# DesignCSG

A comprehensive IDE for OpenSCAD with embedded rendering and import support.

## Note about Naming
The remote repo and folder name for this project is "scadfriend" (short for Software CAD Friend). This is the OLD name. The new name is DesignCSG. The reason I haven't renamed folder and repo is because I have an older repo called DesignCSG on github that some others have forked already. I am considering changing the repo and folder to designcsg2 but that might be even more confusing. Either way. Be aware that the new product/project name is "DesignCSG" (used for all references, display text, etc.), despite the folder/repo name.
